# Setting up the Heel & Serpent Project

How to give Heel & Serpent its own claude.ai Project so any chat there can pick up the work cold.

## 1. Create the Project and add one file

- Name: **Heel & Serpent**
- Add to Project knowledge: `BRAND_BIBLE.md` (this folder). It is the single source of truth.

## 2. Paste these Project instructions

```
This Project runs the Heel & Serpent Instagram page (@heelandserpent): faith-driven motivation for men who get back up. Quiet luxury with a warrior's spine.

The brand bible in Project knowledge is the source of truth. Read it before any work. Its "Working session" section lists the steps: attach the GitHub repo pensiveminds/pensive-minds-media, work only in heel-and-serpent/, install the fonts, build sets with posts/_template/build.py, push to main, check the Metricool handle, then schedule.

Commands: Rise (one post now), Arm (build and schedule next week), Watch (Metricool numbers), Sheathe / Sheathe off (pause or restore scheduled posts).

Non-negotiables: CSB verses verbatim from a published source, reference on every graphic, CSB credit line on every caption that quotes Scripture, every verse logged in SOURCES.md. The fight is spiritual; no politics, current events, prosperity promises or gore. Never touch pensive-minds/ or ranks-and-reason/.

After any change to the bible, update both the Project copy and heel-and-serpent/BRAND_BIBLE.md in the repo.
```

## 3. First message in the new Project

```
Arm
```

or, to just get oriented: `Where does Heel & Serpent stand?`

## Notes

- Memory saved in the Ranks & Reason Project may not be visible from the new Project, depending on its memory setting. Everything that matters is in the bible and the repo, so nothing is lost either way.
- Keep the copy of the bible in the Ranks & Reason Project until the new Project is set up, then delete it there so there is only one live version.
